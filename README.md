# A2C Inventario

Control de herramientas y maquinaria por obra para **Constructora A2C**: dónde está cada activo, cuánto hay y quién lo movió.

- **App:** Flutter (Android · iOS · Web) — `apps/mobile`
- **API:** NestJS + Prisma + PostgreSQL + Redis — `apps/api`
- **Diseño:** versión "Constructora A2C" (blanco, negro y amarillo `#FFC20E`) — [canvas](https://claude.ai/artifact/NSoVekPv3gJuHQjkXjqrpk)
